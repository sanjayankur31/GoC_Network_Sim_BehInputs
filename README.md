# Golgi cell network model

This repository includes scripts for generating networks as well as NeuroML descriptions used for computational modelling of biophysical-detailed models of electrically-coupled cerebellar Golgi cell circuits.

The original model was used in the paper __"Multidimensional population activity in an electrically coupled inhibitory circuit in the cerebellar cortex"__ by Gurnani and Silver in Neuron, 2021.

The model is in the NeuroML2 folder.
